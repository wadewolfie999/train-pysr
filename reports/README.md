# Reports

All reports and diagrams present before the REBUILD baseline are preserved as
historical or provisional review material. They are non-controlling and do not
establish current evidence, execution authority, scientific acceptance,
verdict, phase closure, transition, or LOCK.

This classification includes `dataset_audits/`, `pysr_dial_discovery/`, and
`historical-next-report.dot`. Reuse requires an explicit,
provenance-preserving A1-approved handoff.
